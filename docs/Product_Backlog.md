# Product Backlog — веб-приложение сервиса по ремонту телефонов

## 1. Описание продукта

**Продукт:** веб-приложение для автоматизации работы сервиса по ремонту мобильных устройств.

**Основной пользовательский сценарий:**

> Клиент хочет отремонтировать телефон → создаёт заявку → мастерская получает заявку → сотрудник производит ремонт → клиент отслеживает статус → ремонт завершается → клиент получает уведомление.

---

## 2. Эпики продукта

1. **Ремонт и заявки**
2. **Работа мастерской**
3. **Клиентский сервис**
4. **Управление мастерской**

---
