## Стек

- **Фронт:** Svelte + TypeScript (без контейнеризации)
- **Бэк:** ASP.NET Core Web API (модульный монолит)
- **БД:** PostgreSQL (в Docker)
- **Инфра:** Docker + Docker Compose, HybridCache (гибридный кэш ASP.NET), S3 (RustFS) для фото, Nginx в роли reverse proxy / HTTPS-терминации

## Фичи

- Главная: визитка, часы работы, карта, форма заявки на ремонт, прайс-лист, шаги ремонта, отзывы, пользовательское соглашение
- Витрина: каталог техники, фильтры, бронирование покупки
- Auth: регистрация/вход по телефону или почте, роли (Client / Master)
- Заказ: создание, статусы, история изменения статуса, гарантия на ремонт
- Оплата: эквайринг не планируется, оплата мастеру при оказании услуги (онлайн-оплата — только опционально при остатке времени)
- Уведомления: внешние сервисы email / SMS о смене статуса (конкретные провайдеры TBD)
- Личный кабинет: история заказов, статус ремонта, чат (опционально), профиль
- Панель мастера: заказы, клиенты, статистика/графики, правка прайса/витрины/главной, поиск по фильтрам (отдельных ролей Admin/Manager нет — в мастерской один человек)
- Чат: только для залогиненных, в контексте заказа, отправка фото

## Безопасность — 4.1 Угрозы К · Ц · Д (+ 4.2 OWASP, 4.6 DevSecOps)

- **К:** IDOR заказов, RBAC(в простом виде: Client / Master), JWT + HttpOnly refresh, lockout + rate-limit, секреты в env
- **Ц:** XSS/CSP, EF Core params от SQLi, state-machine статусов, проверка фото (MIME, 5 МБ, S3), аудит изменений
- **Д:** ASP.NET Core Rate Limiting Middleware, HybridCache, health-checks, бэкап PG
